# Wizard Inventroy

By Matthew Green

A menu-based Python program for managing a wizard’s inventory.

## How to run

Installation of python is required, then from IDLE open the file wizard_inventory.py and press F5

## How to use

Type a lowercase command at the Command: prompt and press Enter. Use show to display the numbered inventory, grab to add an item by name, edit to change an item’s name, or drop to remove an item. For edit and drop, enter the item number displayed by show. Type exit to close the program.
